Start Here: A Suggested Learning Path

New to all of this? Work through the nine categories in the order below. Each one builds on the skills from the previous step, and the labs inside each category progress from beginner to advanced. The path is designed so you never hit a lab that assumes knowledge you have not covered yet.

  1. Linux Fundamentals (24 labs): the command line is the foundation of everything else. Get comfortable here first.
  2. Linux Server Administration (12 labs): turn that comfort into administration: installs, services, disks, users, backups.
  3. Version Control & DevOps (6 labs): learn Git now, because every track after this assumes you can version your work.
  4. Networking (16 labs): how traffic actually moves. This underpins both security and cloud work.
  5. Security (18 labs): defense and detection, built directly on your Linux and networking skills.
  6. Python Automation (14 labs): automate the admin and security tasks you already know how to do by hand.
  7. Databases (8 labs): store and query data properly, the backbone behind most services and logs.
  8. Cloud & Azure (9 labs): take the servers and networks you know and deploy them as cloud infrastructure.
  9. Containers & Kubernetes (9 labs): the capstone. Docker and Kubernetes assume comfort with Linux, networking, and the cloud.
