# Linux Labs

24 hands-on labs that build Linux fluency from the ground up: file and text manipulation, permissions, shell scripting, processes, users, storage, and virtualization. Each lab pairs concise steps with expected outputs, troubleshooting, and practice challenges.

Every lab lists concrete learning objectives, walks through each command with expected output and a teaching note, explains how the pieces fit together, and closes with a troubleshooting table, key takeaways, and practice challenges. Follow the labs in order for a complete beginner to capable progression, or jump to any single topic.
