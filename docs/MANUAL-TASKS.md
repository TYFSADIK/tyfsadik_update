# MANUAL-TASKS.md

Everything that needs a human with account access. Each step lists what was
already prepared in the repo so the task is paste-and-click.

## 1. Google Search Console

1. Go to https://search.google.com/search-console and add the property
   `https://tyfsadik.org` (URL-prefix type).
2. Choose the HTML tag verification method, copy the token.
3. Paste it into `index.html` in the empty
   `<meta name="google-site-verification" content="">` tag near the top of
   `<head>`, commit, push.
4. Once verified, submit `https://tyfsadik.org/sitemap.xml` under Sitemaps.

## 2. Bing Webmaster Tools

1. https://www.bing.com/webmasters, add the site (you can import from Google
   Search Console once step 1 is done, which skips re-verification).
2. Otherwise paste the Bing token into the empty
   `<meta name="msvalidate.01" content="">` tag in `index.html`.
3. Submit `https://tyfsadik.org/sitemap.xml`.

## 3. IndexNow

Already wired: key file `149c878bd7aba5f097a1e8ea75a473b8.txt` is at the
site root, and `.github/workflows/indexnow.yml` pings the IndexNow API with
changed URLs on every push to main. Nothing to do unless you want to rotate
the key (then update the file name, its contents, and the workflow).

## 4. Feeds

RSS (`/feed.xml`), Atom (`/atom.xml`), and JSON Feed (`/feed.json`) are
generated by `.tools/build_feeds.py`. Re-run it when site-data.json changes,
or let CI do it (see the quality workflow).

## 5. security.txt

`/.well-known/security.txt` expires 2027-10-22. Update the Expires line once
a year. `_config.yml` includes `.well-known` so the Jekyll pipeline serves it.
